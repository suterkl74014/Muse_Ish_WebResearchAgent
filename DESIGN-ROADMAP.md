# Web Agent Roadmap

## Completed through v0.2

- Standalone AgentSmith credential/config bridge
- Groq / Gemini / OpenRouter / ChatGPT-Codex CLI providers
- Manual, automatic, hybrid provider routing
- Visible persistent Playwright Chromium
- Semantic page observation and browser action loop
- SQLite persistence
- Dark desktop UI
- Multiple persistent chats
- Per-chat messages, tasks, evidence, activity and artifacts
- Configurable working folder
- File creation: text/Markdown, JSON, CSV, DOCX, XLSX, PDF
- Files and Sources inspector tabs
- Pause / manual browser takeover / resume

## v0.3 — planner + research engine

1. Explicit goal object and task DAG.
2. Planner → executor → verifier → replanner loop.
3. Fast HTTP/search research path for ordinary pages.
4. Source-level evidence objects and claim/source citation mapping.
5. Better browser recovery: stale elements, popups, navigation failures, login walls.
6. Research depth presets: Quick / Standard / Deep.

## v0.4 — richer file and web workflows

1. User file attachments/import into working folder.
2. Read common PDF/DOCX/XLSX formats as research inputs.
3. Better spreadsheet/report formatting.
4. Download manager with automatic artifact registration.
5. Saved reusable workflows.

## v0.5 — workers and approvals

1. Parallel research workers.
2. Provider quota/health dashboard.
3. Consequential action approval dialogs.
4. Resume incomplete tasks after restart.
5. Better per-chat browser/session controls.
